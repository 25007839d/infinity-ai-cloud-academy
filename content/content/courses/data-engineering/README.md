# Data Engineering — Industry Ready Program

## 19-module curriculum

This course is designed as a progression from fundamentals to production architecture:

1. Program Kickoff & Industry Foundations
2. Data Engineering Foundation
3. SQL & Database Engineering
4. Python for Data Engineering
5. Linux & Development Tools
6. Data Engineering Core
7. PySpark & Distributed Data Processing
8. Google Cloud Fundamentals & Architecture
9. GCP Data Storage & Analytics
10. GCP Data Processing & Streaming
11. Data Orchestration & Transformation
12. Data Quality & Testing
13. DevOps & CI/CD for Data Engineering
14. Security & Production Engineering
15. Databricks & Lakehouse Engineering
16. Agile & Data Engineering Workplace
17. End-to-End Data Engineering Projects
18. Data Engineering System Design
19. Data Engineer Career & Interview Preparation

Every module contains a presentation source, static presentation artifact, lesson notes, hands-on lab, assignment and a 20-question practice set.
