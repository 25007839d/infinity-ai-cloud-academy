# Source Alignment

The Data Engineering program was expanded using the uploaded teaching resources as reference material.

- **Python:** the 8-session syllabus, session-wise practice questions, OOP, modules/packages, file handling, exception/logging, NumPy and Pandas examples were used to shape Module 04.
- **Apache Beam/Dataflow:** element-wise transforms, aggregation, data-management transforms, I/O, composite transforms and windowing examples were used to shape Module 10.
- **Dataproc/PySpark:** the supplied employee/department datasets, Spark job and Airflow DAG examples were used to shape Modules 07, 10 and 11.
- **Existing module template:** the supplied Quarto module template, Mermaid architecture style and Infinity AI Cloud Academy presentation structure were preserved and expanded.

Where the uploaded resources did not cover a production topic, new material was added around data contracts, observability, security, CI/CD, IaC, lakehouse design, system design and production operations.
