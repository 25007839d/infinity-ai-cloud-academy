# Module 11 Assignment — Data Orchestration & Transformation

## Objective
Demonstrate that you can apply the module concepts in a realistic engineering scenario.

## Scenario
A growing company is building a centralized data platform. Your team owns a pipeline that must be repeatable, observable and safe to operate.

## Deliverables
1. Architecture or solution design.
2. Working implementation / SQL / code where applicable.
3. Sample input and output.
4. At least 5 validation checks.
5. README with setup, assumptions, failure handling and rollback/retry strategy.
6. A short 5-minute walkthrough suitable for a code review.

## Evaluation rubric
- Correctness: 30%
- Engineering design: 20%
- Data quality/testing: 15%
- Reliability/observability: 15%
- Security/cost awareness: 10%
- Documentation: 10%
