🧭 Module roadmap

  • 1. Spark Architecture and Execution ModelDriver plans; executors run tasks; shuffle moves data.
  • 2. RDDs and Functional TransformationsRDDs expose distributed collections and transformations; DataFrames add optimized structured execution.
  • 3. DataFrames and Spark SQLPrefer structured APIs so Spark can optimize the plan.
  • 4. Transformations, Actions and Lazy EvaluationTransformations build a plan; actions execute it.
  • 5. Joins, Aggregations and Window FunctionsJoins and aggregations often trigger shuffle; reduce data before them.
  • 6. Partitions, Shuffle, Repartition and Coalescerepartition reshuffles; coalesce can reduce partitions with less movement.
  • 7. Caching, Broadcast Joins and PerformanceCache only reused data; broadcast only small dimensions.
  • 8. Reading and Writing CSV, JSON and ParquetParquet is columnar and typed; CSV is portable but expensive to parse.
  • 9. PySpark ETL Project: Bronze to Silver to GoldPreserve raw, clean in Silver, publish business-ready Gold.
