# SQL Lab V2

- Admin no longer exposes Lab Instructions.
- SQL Practice Query is the only backend-controlled practice code field shown in the SQL Practice tab.
- If SQL Practice Query is blank, the SQL Practice tab falls back to GitHub file, then configured Drive/Colab resource, then Dataset URL.
- GitHub `/blob/branch/file` links are rendered as code using the corresponding raw.githubusercontent.com URL; repository/folder links remain Open-only.
- Google Drive file/Slides links are previewed with the appropriate Drive/Slides embed URL.
- Existing lab resource tabs remain supported.
