# SQL Practice Source Behavior — V10

For a SQL lab, the Student `SQL Practice` tab is executable.

Priority:
1. `config.starterSql` from the Admin CMS
2. GitHub file URL or Google Drive text/code file configured in `GitHub / Drive Path (embedded)`
3. A GitHub/Drive resource is shown as an embedded viewer when it is not executable text (for example PPT/PDF)
4. Dataset/resource fallback remains unchanged

GitHub SQL/text files are fetched by the LMS server and loaded into the SQL editor. Google Drive `.sql`/text files and Google Docs are fetched by the LMS server and loaded into the SQL editor. PPT/PDF files remain embedded reference material and are not treated as executable code.

Colab remains the only intentional external open action.
